# Matsutake
## Burn - Bury - Build
- Take back control.
- Archive humanity's documents.
- Become a knowledge Monk and serve your community.

This game was made in a two-day scramble during the [2025 bpb game jam](https://www.bpb.de/veranstaltungen/veranstaltungskalender/557211/game-jam-ki/)

Play it on [itch.io](https://karosserie.itch.io/matsutake)!
